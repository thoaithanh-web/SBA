# AI usage · lab04

Người dùng yêu cầu triển khai bốn lab theo PDF, không comment trong code, kiểm thử và push trực tiếp main. AI đã đọc yêu cầu, thiết kế lớp, tạo phần lớn code, tests, Postman collection, tài liệu và phân tích lỗi. Không xác nhận sinh viên đã tự viết/giải thích toàn bộ.

Nguồn phạm vi: Lab04 gốc và Slot18 integration kit. Giữ SQL Server thật, OrchidCategory relationship, Java package naming; alias endpoint để đáp ứng hai tài liệu.

Đã kiểm chứng bằng build, test assertions, Newman HTTP requests và SQL Server schema/FK, CRUD, rollback tests, negative requests và restart persistence. Evidence được lưu có chọn lọc, không lưu mật khẩu hoặc dump toàn bộ log.

Sinh viên tự thực hiện Human Gate/vấn đáp không dùng AI: trace một POST/GET qua các lớp, giải thích test boundary, sửa một yêu cầu mới và demo trực tiếp. Giải thích owning side/mappedBy/FK, transaction, category lookup, JSON recursion và SQL/Java mapping. Các phần này chưa có bằng chứng để đánh dấu PASS.
