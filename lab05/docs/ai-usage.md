# Sử dụng AI và việc sinh viên cần nắm

Codex đã đọc hướng dẫn Lab05 và cấu trúc đính kèm, triển khai backend/frontend, tạo database local theo ủy quyền, viết/chạy kiểm thử, đối chiếu SQL và chuẩn bị tài liệu. Mật khẩu thật chỉ nằm ở cấu hình local được Git bỏ qua, không nằm trong frontend hoặc source công khai.

Ảnh SVG được tái sử dụng từ tài sản do dự án tự tạo trong Lab01; minh họa Phalaenopsis được đổi sang màu trắng. Không có ảnh chụp hoa lan thật hoặc upload ảnh trong bài.

Sinh viên cần tự demo và giải thích: main.tsx routing, Axios base URL, CORS, controlled form/checkbox, useEffect cleanup, HTTP status, constructor injection, @Transactional, JpaRepository, entity/column mapping, JSON boolean naming và vai trò SQL Server. Các kiểm thử tự động không thay thế khả năng tự giải thích hoặc sửa code trực tiếp.
